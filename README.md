# Algorithm Lab

数据结构与算法复习的 Java 学习代码。

## 目录结构

- `src/main/java/com/chinazhouwy/algolab/sort`：排序算法
- `src/main/java/com/chinazhouwy/algolab/leetcode`：LeetCode 题解
- `src/main/java/com/chinazhouwy/algolab/utils`：通用数组工具
- `src/main/java/com/chinazhouwy/algolab/datastructure`：线性表、栈队列、树、图等数据结构代码

## 包名

统一根包为 `com.chinazhouwy.algolab`，避免旧项目中的大小写混用和过于笼统的类名。

就是随手写写，不求过分严谨，只是知道一下原理，其实写了一会儿也忘了，唉~~~~~~
